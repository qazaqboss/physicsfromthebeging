# Физика с самого начала

Интерактивный курс физики на **12 лет**: 12 классов по 6 тем плюс 6 углублённых = **78 тем** — от «твёрдое, жидкое, газ» в 1 классе до теории относительности, квантов, **матриц поворота, матриц Паули и сферы Блоха** в 12-м. В каждой теме — теория, формулы, опыт и вопрос «Проверь себя»; прогресс сохраняется в браузере.

Откройте `index.html` в браузере — сайт собран в один файл (плюс `vendor/three.min.js` и `audio/`) и работает без сервера.

## Лаборатории

**Изометрические приборы (Anatomy, SVG):** жёлоб Галилея (7.1), воздушный трек (7.2), закон Ома (8.5), маятник Ньютона (9.1), пружинный маятник (9.3), опыт Мельде (9.4), цилиндр с поршнем (10.4), оптическая скамья (11.5).

**3D-лаборатории (Three.js, в стиле Anatomy — изометрическая камера, бумажные тона, контуры, плита на ножках; вращаются пальцем):** поле двух зарядов (8.4), орбиты и законы Кеплера (9.5), электромагнитная волна (11.4), интерференция (11.6), матрица поворота с живой матрицей 3×3 (12.4), спин и сфера Блоха с матрицами Паули (12.5), заряд в магнитном поле — спираль Лоренца (11.1), пространство-время и матрица Лоренца (12.7), орбитали водорода из облака измерений |ψ|² (12.8).

Страницы: `#/` — карта курса, `#/g/7` — класс, `#/t/7-1` — тема. Содержание курса — `src/course/*.js`.

## Сборка

Нужен только Node.js 18+ (без зависимостей):

```sh
node build.mjs
```

Скрипт склеивает `src/` в один `index.html` и собирает `banner.html`. Three.js (r149, UMD) лежит в `vendor/` и подгружается только на страницах с 3D.

### Баннер для ссылки

`og.png` (2400×1260) — превью, которое показывают Telegram, VK, WhatsApp, X и другие сервисы. Мета-теги в `src/index.html` ссылаются на адрес GitHub Pages: `https://qazaqboss.github.io/physicsfromthebeging/og.png`. Если сайт будет жить по другому адресу, замените его в `og:url`, `og:image` и `twitter:image`.

Перерисовать баннер (нужен Playwright):

```sh
node build.mjs && node scripts/banner.cjs
```

## Голосовой гид

Кнопка «Гид Лина» (и «Экскурсия с голосовым гидом» на первом экране) запускает экскурсию по курсу из 14 остановок: Лина переходит по страницам, рассказывает о каждой лаборатории, страница сама прокручивается к прибору и подсвечивает его, субтитры подсвечиваются слово в слово, а в главах с кнопкой «Пуск» опыт запускается сам. На странице каждого класса Лина рассказывает о нём (кнопка «Лина рассказывает о классе»), а на страницах лабораторий есть кнопка «Лина объясняет опыт».

Голос сделан движком **OmniVoice** из [VoiceStudio](https://github.com/debpalash/VoiceStudio) (модель `k2-fsa/OmniVoice`, Apache-2.0): сначала голос «спроектирован» по описанию (*female, young adult, moderate pitch*, русский), затем каждая реплика озвучена клонированием этого сохранённого голоса, поэтому он одинаковый во всех главах. Готовые файлы лежат в `audio/guide/*.mp3`, сайт работает без сервера и без сети.

Тексты гида — в `src/guide-steps.js`, вступления к классам — в `src/course-intros.js`. Чтобы переозвучить после правки (нужны Python 3.11+, `omnivoice` из репозитория VoiceStudio, `faster-whisper`, ffmpeg; модель OmniVoice ~3,2 ГБ, на процессоре ~7 с счёта на 1 с речи):

```sh
node scripts/voice/steps-json.mjs > steps.json
python scripts/voice/narrate.py <папка-модели-OmniVoice> steps.json wav            # можно указать id реплик: ch1 ch2
python scripts/voice/finish.py <папка-faster-whisper> steps.json wav audio/guide src/guide-data.json
node build.mjs
```

`scripts/voice/design_voice.py` пересоздаёт сам голос (`scripts/voice/voice-lina.wav`).
