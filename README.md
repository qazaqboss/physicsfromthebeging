# Физика с самого начала

Интерактивный учебник физики: восемь живых опытов на лабораторном столе — от жёлоба Галилея до оптической скамьи. Каждый прибор нарисован в изометрии, его можно трогать, а числа на табло вычисляются той же моделью, что двигает детали.

Откройте `index.html` в браузере — сайт собран в один файл и работает без сервера.

## Главы

| № | Тема | Прибор | Закон |
|---|---|---|---|
| 01 | Кинематика | Жёлоб Галилея с воротами 1 : 4 : 9 : 16 | s = at²/2, a = 5/7·g·sin α |
| 02 | Динамика | Воздушный трек, блок и грузик | a = m·g / (M + m) |
| 03 | Импульс | Маятник Ньютона | Σmv = const |
| 04 | Колебания | Пружинный маятник на штативе | F = −kx, T = 2π√(m/k) |
| 05 | Волны | Опыт Мельде (стоячая волна) | fₙ = n·v / 2L |
| 06 | Термодинамика | Цилиндр с поршнем на плитке | pV = νRT |
| 07 | Электричество | Цепь с реостатом, амперметром и лампой | I = U/R |
| 08 | Оптика | Оптическая скамья: свеча, линза, экран | 1/F = 1/d + 1/f |

В каждой главе: короткая теория, формулы, пошаговый опыт и вопрос «Проверь себя». Прогресс и тема (светлая/тёмная) запоминаются в браузере.

## Сборка

Нужен только Node.js 18+ (без зависимостей):

```sh
node build.mjs
```

Скрипт склеивает `src/` в один `index.html` и собирает `banner.html`.

### Баннер для ссылки

`og.png` (2400×1260) — превью, которое показывают Telegram, VK, WhatsApp, X и другие сервисы. Мета-теги в `src/index.html` ссылаются на адрес GitHub Pages: `https://qazaqboss.github.io/physicsfromthebeging/og.png`. Если сайт будет жить по другому адресу, замените его в `og:url`, `og:image` и `twitter:image`.

Перерисовать баннер (нужен Playwright):

```sh
node build.mjs && node scripts/banner.cjs
```

```text
src/
```

## Голосовой гид

Кнопка «Гид Лина» (и «Экскурсия с голосовым гидом» на первом экране) запускает экскурсию по сайту: Лина рассказывает о каждой главе, страница сама прокручивается к нужному прибору и подсвечивает его, субтитры подсвечиваются слово в слово, а в главах с кнопкой «Пуск» опыт запускается сам. В каждой главе есть кнопка «Послушать объяснение».

Голос сделан движком **OmniVoice** из [VoiceStudio](https://github.com/debpalash/VoiceStudio) (модель `k2-fsa/OmniVoice`, Apache-2.0): сначала голос «спроектирован» по описанию (*female, young adult, moderate pitch*, русский), затем каждая реплика озвучена клонированием этого сохранённого голоса, поэтому он одинаковый во всех главах. Готовые файлы лежат в `audio/guide/*.mp3`, сайт работает без сервера и без сети.

Текст гида — в `src/guide-steps.js`. Чтобы переозвучить после правки (нужны Python 3.11+, `omnivoice` из репозитория VoiceStudio, `faster-whisper`, ffmpeg; модель OmniVoice ~3,2 ГБ, на процессоре ~7 с счёта на 1 с речи):

```sh
node scripts/voice/steps-json.mjs > steps.json
python scripts/voice/narrate.py <папка-модели-OmniVoice> steps.json wav            # можно указать id реплик: ch1 ch2
python scripts/voice/finish.py <папка-faster-whisper> steps.json wav audio/guide src/guide-data.json
node build.mjs
```

`scripts/voice/design_voice.py` пересоздаёт сам голос (`scripts/voice/voice-lina.wav`).
